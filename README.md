# AI QA Python Alapok

Ez a repozitórium az AI QA (Minőségbiztosítás) képzésem során készült gyakorlatokat tartalmazza.

## Tartalom
* **Python Alapok**: Változók, listák, szótárak.
* **Logikai vezérlés**: Ciklusok és feltételes utasítások.
* **Hibakezelés**: `try-except` és `assert` használata tesztelési környezetben.
* **GitHub Verziókezelés**: Profi munkafolyamat gyakorlása.
